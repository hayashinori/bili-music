# Bili音乐 0.7.3

## 0.7.3：性能优化与文字标识

- 左上去掉音乐图标，仅保留 Bili音乐文字。
- 播放器暂停时采用 1 秒轮询，播放时保持 400 毫秒采样；播放、暂停、跳转、音量、倍速和结束事件即时报告。缓存视频元素，降低重复 DOM 扫描；SPA 切视频时立即重新探测。
- 布局在动画帧内合并，并跳过相同布局的主进程消息；隐藏页面不再滚动或更新歌词高亮。
- 歌曲列表按需构建，歌词与列表用 DocumentFragment 一次插入；重复设置值、播放图标与循环图标不再反复写入 DOM。稳定媒体信息不重复解析列表匹配 URL。
- 最小化时暂停唱片动画和主窗口结构状态推送，恢复时补发完整状态；桌面歌词和播放继续独立工作。
- 性能测试验证了消息和 DOM 工作量减少，没有进行可靠的前后 CPU/内存百分比对照。B 站网页与视频解码仍是资源开销的一部分。

## 0.7.2：播放栏列表按钮背景

- 歌曲列表入口改为与播放栏一致的透明图标按钮，修复浅色设置下进入沉浸模式时仍显示白底的问题。

## 0.7.1：扩大歌词空间

- 普通「正在听」的歌词偏移、字幕源、刷新和版本选择移至左栏。
- 右栏使用更高的独立滚动歌词区，左栏内容较长时歌词栏保持在可视区域。
- 去掉沉浸模式唱片封面中央的小圆点。

## 0.7.0：全局暗色与歌曲列表

- 顶栏月亮按钮快捷切换明暗；「歌词与设置 → 界面模式」支持浅色、暗色、跟随系统。保留主题色，暗色下自动调整主题文字的可读性。
- 新增本机「歌曲列表」，支持从正在听、最近播放、我的收藏添加，也可粘贴完整 B 站视频链接或 BV 号添加。相同视频/分 P 去重，列表与顺序自动保存，最多 500 首。
- 长按歌曲文字或拖动柄约 0.3 秒后上下拖动，松开保存；靠近列表可视区上下边缘自动滚动。方向按钮及拖动柄上的方向键也可排序；可逐首移除。
- 底部新增上一首、下一首和循环模式按钮。支持顺序播放（列表末尾停止）、列表循环、单曲循环；播放结束后自动执行。手动上一首/下一首会切换歌曲，不受单曲循环限制。
- 歌曲列表是 B 站视频播放队列，不会更改云端收藏或下载音频。粘贴添加的视频在首次播放后会更新标题；登录与视频播放权限沿用当前 B 站会话。

## 0.6.1：唱针动画与歌词排版

- 沉浸模式播放时唱针从抬起位置平滑落入唱片，暂停时归位；播放中进入沉浸模式也会落针。动画约 0.72 秒，遵循系统减少动画设置。
- 加宽歌词栏，统一普通句和当前句字号/字重，避免点亮时重新换行；调整日文字体回退、行高、翻译字号与间距。

## 0.6.0：沉浸模式与搜索清空

- 顶部搜索框有文字时显示「×」，点击清空并保持输入焦点，不提交搜索。
- 「正在听」右上角的桌面歌词、找回歌词按钮旁增加「沉浸模式」。深色唱片/歌词双栏隐藏侧栏与匹配工具，保留双语、歌词收藏、点击歌词定位与底部播放控制。
- 唱片使用当前视频封面；播放时旋转、暂停时停止，遵循系统减少动画偏好。没有封面时显示音乐图标。
- 点击左上「退出沉浸模式」或按 Esc 返回，恢复视频与原布局；沉浸模式不重载视频或更改音频模式设置。

## 0.5.1：歌词框拉伸与长句修复

- 解锁桌面歌词后，拖动左右边缘拉宽，拖右下角调整宽高；松开鼠标应用尺寸。边缘支持方向键微调，设置页可输入宽高。
- 尺寸在本机自动保存，重启恢复；窗口限制在屏幕工作区内。
- 原文与高亮层使用一致的单行布局，长句按宽度适应，翻译独立适应，避免断行与高亮错位。
- 仍不启用 Windows 原生透明窗口连续缩放；用户松开拖拽时仅重建一次窗口，以保留透明歌词的显示兼容性。

## 0.5.0：快捷切源与四源歌词

- 在「正在听」歌词版本列表上方直接选择字幕源，不必进入设置。支持网易云音乐、QQ 音乐、酷狗音乐、LRCLIB 和自动合并，切源立即用当前搜索词重新搜索。
- 「刷新源」清除所选来源的搜索与歌词缓存，重新获取候选和字幕；选择自动合并时刷新全部来源。收藏歌词不被清除，同一版本刷新保留已有时间偏移。
- 各来源显示搜索结果数量、无结果或连接失败，悬停失败状态可看错误。部分来源失败时其余来源继续参与匹配；全部失败保留当前字幕。
- QQ 音乐读取可用翻译轨；酷狗通过曲库歌曲哈希匹配 LRC。没有翻译时可自行导入翻译；不保证每个来源、每首歌都有双语。
- 站点接口可能临时失败，点击刷新可重试。这里是歌词来源，不改变 B 站音频来源。

## 0.4.0：播放管理、账号收藏与性能

- 桌面高亮按播放时钟、暂停和倍速在本地逐帧插值，不再每 250 毫秒跳一下。省资源模式以约 30 帧绘制，关闭省资源模式后目标为 60 帧；它仍是按行时间估算，并非真实逐字时间轴。
- 在「歌词与设置」中分别调整桌面主行、桌面翻译/下一行和主窗口翻译的字号。
- 「最近播放」支持卡片/列表切换、逐条删除、一键清空和撤销。这些操作只影响本机记录，不删除 B 站云端历史或收藏。
- 登录后通过 B 站账号接口显示头像、昵称；头像或昵称未刷新时，点击账号旁的刷新按钮。
- 「我的收藏」读取当前账号自己创建的收藏夹，支持选择收藏夹、分页加载、点击视频直接进入「正在听」播放；失效视频禁用。
- 「仅听音频 / 显示视频」切换画面显示。它保留 B 站播放器，不等于只下载音频；「关闭视频」则停止播放并销毁网页，保留账号登录与最近记录。
- 音质栏仅操作 B 站官方播放器已有的音轨选项，并检查切换是否确认。原视频/账号未提供 Hi-Res 或杜比时只显示标准音质；没有人为转换、伪造无损或绕过账号权限。
- 播放时钟与完整状态分开发送，不再为每次进度重复传输/渲染整个歌词、候选和历史；缓存视频视图边界，减少重复原生布局；封面懒加载。省资源模式减少后台网页绘制并在音乐界面隐藏弹幕。

退出旧版本后运行新版即可，原有登录与字幕数据继续使用相同目录。

## 直接使用

1. 解压 `伴词桌面-0.7.3-Windows-x64.zip`，双击其中的 **BanCi.exe**。请保留同文件夹里的其他文件。
2. 在右上角点击 **登录 B 站**，在内嵌的 B 站官方页面自行扫码或登录。也可以不登录，直接浏览公开视频。
3. 搜索音乐、粘贴 B 站链接或 BV 号，打开视频。点击左侧「正在听」切换到音乐与歌词界面；点击「桌面歌词」即可悬浮显示。

无需安装浏览器扩展、Node.js 或 Python，无需启动辅助程序、开放端口或复制配对码。

## 已整合的功能

- 内嵌 B 站官方网页，登录会话自动保留在应用自己的浏览器分区中；可在 B 站页面浏览、搜索并选择视频。
- 输入完整 HTTPS 视频链接、`b23.tv` 链接、BV 号或关键词；关键词在 B 站官方搜索页打开。
- 自动读取当前视频的标题、播放时间、时长、暂停状态和倍速。跳转视频、同页换视频或分 P 时清空旧歌词，按新标题重新匹配。
- 网易云音乐、QQ 音乐、酷狗音乐与 LRCLIB 四来源；按照歌名、标题中的歌手、时长与版本排序，自动选用最高的可用同步歌词；来源有翻译时同步读取。
- 歌词随视频暂停、拖动和倍速更新；主窗口可以播放/暂停、前后跳 10 秒、拖动进度、调音量和倍速；点击歌词可跳到该句。
- 双语显示、LRC / SRT / VTT 原文与翻译文件导入、粘贴自定义字幕。支持 UTF-8 与 GB18030，字幕文件上限 1 MB。
- 全局偏移与按句对齐。字幕与偏移按视频记录；手选或自定义字幕在再次打开同视频时恢复。
- 原生置顶桌面歌词窗口，默认深色兼容背景、可选透明；当前句进度着色，第二行显示翻译或下一句，支持拖动、边缘调整尺寸、字号颜色与文字不透明度、锁定鼠标穿透。手动调整尺寸在松开时应用，避免透明窗口连续缩放导致显示失效。
- 最近播放记录（最多 30 条）、字幕缓存（最多 40 个视频，约 7 MB），保存在本机。

快捷键：`Ctrl + Alt + D` 显示/隐藏桌面歌词，`Ctrl + Alt + L` 解锁歌词并打开主窗口。主窗口非输入状态下按空格控制播放。歌词锁定后也可以在「歌词与设置」中解除锁定。

## 登录与数据

登录页面来自 `https://passport.bilibili.com/login`；密码、验证码与二维码流程由 B 站网页处理，伴词没有自建密码输入框。登录成功以浏览器会话 Cookie 保留；应用只将是否已登录的布尔状态传给自己的界面，不导出登录 Cookie。退出账号可在内嵌 B 站官方页面操作。

应用数据保存在 Electron 的本机用户数据目录中（通常在 `%APPDATA%` 下）。B 站远程网页使用隔离、禁用 Node 集成的沙箱视图，与本机文件、字幕导入和窗口操作分开。测试浏览器分区与测试数据不包含在发布包内。

自动匹配会将清理后的歌名关键词发送给所选歌词来源；完整视频标题在本地参与排序。没有分析统计或云端账号系统。关闭自动匹配可只用导入字幕。

## 自动对准的范围

本版使用来源已有的歌词时间轴，按照视频媒体的 `currentTime` 同步；视频与原曲版本一致时可直接对准。片头、翻唱、现场与剪辑版的差异可用全局偏移或「按句校准」修正。

**没有实现音频听歌识曲、歌声强制对齐或自动翻译。** 不同演唱节奏、中途剪切等情况无法仅靠一个偏移完全修复。桌面着色按句间时间估算，不是真实逐字卡拉 OK 时间轴。

## 环境边界

B 站的网络、地区、账号风控、验证码、视频权限与曲库限制仍由站点决定；内嵌登录不保证绕过这些限制。网易云接入匿名可用的站点接口，包含 305 搜索兼容处理，接口也可能变化。页面或歌词源失败会在界面提示，可刷新、重试或导入字幕。

目前面向 Windows x64，尚未提供代码签名、安装器、自动更新、收藏夹编辑/云端同步、离线音频下载或真正的音频强制对齐。关闭主窗口会退出应用；最小化可继续播放及显示桌面歌词。内嵌 B 站网页与视频解码仍有资源开销；本版没有承诺固定的 CPU/内存降低幅度。

## 开发

```powershell
npm install
npm start
npm test
npm run package
```

`tests/desktop-smoke.cjs` 使用 Playwright 驱动真实 Electron 窗口、原生媒体时间轴和独立测试会话。测试视频页及歌词来源可控，测试不会登录真实账号。详情与真实网络测试记录见 `VALIDATION.md`。

实现依据：[Electron WebContentsView](https://www.electronjs.org/docs/latest/api/web-contents-view)、[Electron 安全建议](https://www.electronjs.org/docs/latest/tutorial/security/)、[LRCLIB](https://lrclib.net/docs)。

新增来源接口结构参考：[Listen 1 QQ 适配器](https://github.com/listen1/listen1_chrome_extension/blob/master/js/provider/qq.js)、[Listen 1 酷狗适配器](https://github.com/listen1/listen1_chrome_extension/blob/master/js/provider/kugou.js)、[LyricsKit 酷狗接口](https://github.com/ddddxxx/LyricsKit/blob/master/Sources/LyricsService/Provider/Kugou.swift)。本项目只获取歌词，不调用这些服务的音频下载接口。
